What is a hash?

A hash is a fixed-length fingerprint of your input. The same text always produces the same hash, but you can't reverse a hash back to the original text. Hashes are used to verify file integrity, store passwords safely, and detect changes in data.

Is my text uploaded?

No. Hashing is done entirely in your browser with the built-in Web Crypto API — nothing is sent anywhere.

Why no MD5?

MD5 is considered insecure and isn't supported by the browser's crypto API. SHA-256 and above are the modern, recommended choices.
