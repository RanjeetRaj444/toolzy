What is a Unix timestamp?

A Unix timestamp is the number of seconds since 1 January 1970 (UTC). It's a compact, timezone-independent way to store a moment in time, used throughout programming and databases.

Seconds or milliseconds?

This tool treats input as seconds. JavaScript uses milliseconds internally, so it multiplies by 1000 automatically.
