Compare Two Texts and Highlight Differences

Whether tracking document revisions, checking legal contract amendments, comparing code versions, or proofreading student essays, this text diff checker compares two passages side-by-side and clearly highlights added, modified, and deleted lines.

How the Diff Algorithm Works

Using the Longest Common Subsequence (LCS) comparison model, lines present in the original but omitted in the revision are flagged in red, while newly inserted lines are highlighted in green.

Frequently asked questions

Is the diff tool case-sensitive?

Yes. The comparison checks exact character differences, capitalization, indentation, and punctuation.

Can I compare source code and JSON files?

Yes. You can paste HTML, JavaScript, Python, JSON, CSS, or raw prose text.

Are my sensitive documents uploaded anywhere?

No. The comparison runs entirely on your local machine using client-side JavaScript. No text is transmitted over the internet.
