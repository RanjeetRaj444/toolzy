What is Base64?

Base64 is a way of representing binary or text data using only 64 safe characters (A–Z, a–z, 0–9, + and /). It's widely used to embed images in CSS/HTML as data URLs, to send data in JSON or URLs, and in email attachments.

Does it handle emojis and accents?

Yes. This tool encodes text as UTF-8 first, so Unicode characters like é, ü and 😀 work correctly.

Is Base64 encryption?

No. Base64 is encoding, not encryption — anyone can decode it. Never use it to protect secrets.
