Which format should I choose?

  • PNG — lossless, supports transparency. Best for logos, icons, screenshots.
  • JPG — smaller files for photos, no transparency.
  • WebP — modern format, smallest size with great quality.

Are my images uploaded?

No. Conversion happens entirely in your browser using the HTML canvas.
