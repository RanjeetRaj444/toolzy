About JSON formatting

JSON (JavaScript Object Notation) is the most common format for sending data between apps and APIs. A formatter makes compact JSON readable by adding indentation, while a validator checks that your JSON is correctly structured before you use it.

Is my JSON sent to a server?

No. Parsing and formatting happen entirely in your browser — your data never leaves your device.

What does "minify" do?

It removes all unnecessary whitespace to make the JSON as small as possible — useful for saving bandwidth.
