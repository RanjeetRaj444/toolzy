HEX, RGB and HSL explained

  • HEX — a 6-digit code like #635bff, common in CSS and design tools.
  • RGB — red, green, blue values from 0–255, e.g. rgb(99, 91, 255).
  • HSL — hue, saturation, lightness — intuitive for adjusting shades.
