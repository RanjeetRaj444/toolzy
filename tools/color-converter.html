HEX, RGB and HSL Color Formats Explained

Colors in web and graphic design are defined across multiple color models depending on the software or coding framework you use:

  • HEX: A 6-character hexadecimal code prefixed with '#' (such as #635bff). It represents the red, green, and blue components in base-16 and is the industry standard in CSS and HTML.
  • RGB: Defines red, green, and blue values on an 8-bit scale from 0 to 255 (e.g. rgb(99, 91, 255)). Widely used in digital displays and UI libraries.
  • HSL: Hue (0° to 360° on the color wheel), Saturation (0% to 100%), and Lightness (0% to 100%). HSL is the most intuitive format for creating lighter tints or darker shades of a base hue.

Frequently asked questions

How do I convert a 3-digit HEX code to 6 digits?

Duplicate each character. For example, #abc expands to #aabbcc.

Which color format is best for CSS design systems?

HSL and modern CSS Color Module 4 (OKLCH) are ideal for theming and color palettes, while HEX remains standard for quick copy-pasting from Figma or Adobe XD.
