When do you need URL encoding?

URLs can only contain certain characters. Spaces, &, ?, # and non-English letters must be "percent-encoded" (e.g. a space becomes %20) so links and query parameters work correctly.

Encode vs encodeURIComponent?

This tool uses component encoding, which escapes characters like &, = and ? — ideal for query-string values.
